# 🧠 Bilgi Yarışması

Bu proje, **HTML**, **CSS** ve **JavaScript** kullanılarak hazırlanmış eğlenceli bir bilgi yarışmasıdır.

Oyuncu ekrandaki soruları okur, doğru olduğunu düşündüğü cevabı seçer ve puan kazanmaya çalışır.

## 🧱 HTML Nedir?

HTML, bir web sayfasının **iskeletini ve içindeki bölümleri** oluşturur.

Gerçek hayatta bir ev düşünelim. Evin duvarları, kapıları ve odaları varsa web sitesinde de başlıklar, yazılar, resimler ve düğmeler vardır. İşte bunları sayfaya **HTML yerleştirir**.

Bilgi yarışmamızda HTML;

- Sorunun,
- Cevap seçeneklerinin,
- Düğmelerin

sayfada bulunmasını sağlar.

## 🎨 CSS Nedir?

CSS, web sayfasının **güzel görünmesini** sağlar.

Bir evin duvarlarını boyamak, odaları süslemek ve eşyaların yerini düzenlemek gibidir. HTML evi kurar, **CSS ise evi süsler**.

Bilgi yarışmamızda CSS;

- Renkleri belirler,
- Yazıların büyüklüğünü ayarlar,
- Düğmeleri güzelleştirir,
- Sayfadaki bölümleri düzenler.

## ⚙️ JavaScript (JS) Nedir?

JavaScript, web sayfasının **çalışmasını ve hareket etmesini** sağlar.

Bir oyuncak robot düşünelim. Robotun gövdesi HTML, renkleri CSS'tir. Robotun komutları anlayıp hareket etmesini sağlayan beyni ise **JavaScript'tir**.

Bilgi yarışmamızda JavaScript;

- Seçilen cevabı kontrol eder,
- Cevabın doğru veya yanlış olduğunu gösterir,
- Puanı hesaplar,
- Yeni soruya geçilmesini sağlar.

## 🏠 Kısaca Hatırlayalım

| Teknoloji | Görevi | Gerçek hayat örneği |
|---|---|---|
| **HTML** | Sayfanın yapısını kurar | Evin duvarları ve odaları |
| **CSS** | Sayfayı güzelleştirir | Evin boyası ve süsleri |
| **JavaScript** | Sayfayı çalıştırır | Evin elektriği veya robotun beyni |

**HTML kurar, CSS süsler, JavaScript çalıştırır!** 🚀
